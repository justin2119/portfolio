# Justin BINA — Portfolio

Bilingual French/English React portfolio for Justin BINA, Developer & Teacher.

## Features

- FR / EN language switch with session persistence
- Style Carré visual system: #263238, #37474F, #4CAF50, zero-radius geometry
- Sharp profile-photo placeholder ready to replace with a real image
- Responsive, accessible sections for About, philosophy, skills, projects, education, and contact

## Run locally

```bash
npm install
npm run dev
npm run build
```
